# Edge Switch v2.0.0-alpha.8（Fork 修复版）

修复首次统一历史时，终端 Codex 与 VS Code 附带版本的数据库升级进度不同而被错误阻止的问题。原实现要求两份表结构完全相同，现在先核对升级版本、校验值及成功状态，选用较新结构，再按字段导入较旧历史。新增可空字段与有默认值的字段自动兼容，完整源库继续保留备份。

同时修复历史重建索引后再次变空的问题：Codex 会读取会话内后续的 `session_meta` 与 `thread_settings_applied` 事件，因此统一这些记录的供应商元数据，保留消息正文原始字节。已完成旧版迁移的环境会在关闭远程 Codex 后补做升级，并完整备份到 `codex-history-backup-v2-时间戳`。文件逐个原子替换，数据库使用事务更新；中断后重试不会跳过未完成的升级。

不兼容升级链、失败的数据库升级、丢失的旧字段、新增无默认值必填字段及字段类型或主键变化仍会停止迁移，避免覆盖原记录。

验证覆盖迁移进度 59 与 62 的实际表结构，以及双向输入顺序、新增表和字段、错误校验值、失败升级和原库保留。板卡历史迁移后核实 3 条记录、数据库完整性通过且原件备份存在；未发送模型推理请求。
