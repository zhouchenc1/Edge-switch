# Edge Switch v2.0.0-alpha.7（Fork 修复版）

修复 Linux 远程 VS Code Codex 插件在官方账号与 API 模式之间切换后，历史列表因数据目录和供应商标识不同而变空的问题。同一工作环境共享会话、归档、终端历史和 SQLite 索引；OAuth 与 API Key 继续分别保存。

首次同步会在关闭该环境的 Codex 进程后迁移旧记录，完整原件保留在 `codex-history-backup-v1`。迁移只统一会话头部与索引标识，保留消息正文及恢复会话需要的工具元数据；冲突、版本差异和中断后新增数据会阻止覆盖。已有文件链接和固定 `sqlite_home` 确保后续新增会话、索引版本继续共用历史。

同时将旧版 Python SSH Agent 引导程序改由 SSH 标准输入传输，避免历史迁移逻辑增长后超过 Windows 命令行限制。Windows 云端打包直接使用当前 PowerShell 7 执行，保留 WebView2 签名验证。

验证包含 Linux 实际文件链接、SQLite WAL、备份、历史合并、账号凭据隔离、冲突及中断重试，以及 Windows Python 回归。隔离的 Codex app-server 验证官方/API 配置能列出同一历史会话，未执行模型推理。真实板卡与实际账号的切换仍需安装此版后验证。
